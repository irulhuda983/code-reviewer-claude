## 附錄：常見問題範例

### 範例 1：localStorage 儲存敏感 Token

**嚴重度**: 🔴 嚴重

**問題描述**:

```typescript
// ❌ 不安全：使用 localStorage 儲存 Token
localStorage.setItem("accessToken", token);
```

**建議修正**:

```typescript
// ✅ 方案 1：使用 httpOnly Cookie (推薦)
// 在 API Route 中設定
cookies().set("accessToken", token, {
  httpOnly: true,
  secure: true,
  sameSite: "lax",
});

// ✅ 方案 2：使用 sessionStorage (次要選擇)
sessionStorage.setItem("accessToken", token);
```

---

### 範例 2：缺少錯誤處理

**嚴重度**: 🟡 重要

**問題描述**:

```tsx
// ❌ 問題：未處理 error 和 loading 狀態
export function UserProfile() {
  const { data } = useUserProfile();
  return <div>{data.name}</div>; // data 可能是 undefined
}
```

**建議修正**:

```tsx
// ✅ 正確：完整處理所有狀態
export function UserProfile() {
  const { data, isLoading, isError, error } = useUserProfile();

  if (isLoading) return <LoadingSpinner />;
  if (isError) return <ErrorMessage message={error.message} />;
  if (!data) return <EmptyState message="User not found" />;

  return <div>{data.name}</div>;
}
```

### 範例 3：useEffect 依賴項遺漏

**嚴重度**: 🟡 重要

**問題描述**:

```tsx
// ❌ 問題：userId 應該在依賴陣列中
useEffect(() => {
  fetchUser(userId);
}, []); // 遺漏 userId
```

**建議修正**:

```tsx
// ✅ 正確：包含所有依賴
useEffect(() => {
  fetchUser(userId);
}, [userId]);
```
